## ✨ Features

- 📧 **Top Bar** — Email and phone number always visible
- 🏠 **Hero Section** — Eye-catching gradient banner with CTA buttons (Call/WhatsApp & Book Now)
- 📍 **Location Card** — Store address with Google Maps directions link
- 🚘 **Fleet Showcase** — 6 cars with price badges, km/hour specs, and Enquiry/WhatsApp buttons
- ❓ **Why Choose Us** — 6 feature cards (Well-Maintained, Sanitized, 24/7 Support, Transparent Pricing, Safe Rides, Low Fare)
- ⭐ **Customer Reviews** — 4 testimonial cards with star ratings
- 📊 **Stats Counter** — Animated counters (Experience, Fleet, Happy Customers)
- 📱 **Floating Buttons** — WhatsApp (bottom-right) + Phone (bottom-left)
- 💬 **WhatsApp Integration** — Every button links to WhatsApp with pre-filled message
- 📱 **Fully Responsive** — Works perfectly on desktop, tablet, and mobile

## 🚀 Getting Started

### Option 1: Open Locally
```bash
# Clone the repository
git clone https://github.com/yaminikrishna9652/jessi-self-drive-cars.git

# Open in browser
open index.html
```

### Option 2: Deploy with GitHub Pages
1. Push this repository to GitHub
2. Go to **Settings** → **Pages**
3. Under Source, select **Branch: main** → **/ (root)**
4. Click **Save**
5. Your site will be live at: `https://yaminikrishna9652.github.io/jessi-self-drive-cars/`
