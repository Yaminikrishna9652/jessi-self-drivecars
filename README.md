## ✨ Features

### 🏠 Homepage
- 📧 **Top Bar** — Email and phone number always visible
- 🔗 **Sticky Navbar** — Logo, navigation links, Call Now CTA, mobile hamburger menu
- 🎯 **Hero Section** — Eye-catching gradient banner with Call/WhatsApp & View Fleet buttons
- 📍 **Location Card** — Store address with Google Maps directions
- 🚘 **Fleet Showcase** — 6 cars with price badges, km/hour specs, Enquiry & WhatsApp buttons
- ❓ **Why Choose Us** — 6 feature cards
- ⭐ **Customer Reviews** — 4 testimonial cards with star ratings
- 📊 **Animated Stats Counter** — Years, Fleet, Happy Customers

### 🚗 Car Detail Page (click "Enquiry Now")
- Large car image with full specifications
- Feature list with checkmark icons
- **12-hour / 24-hour** duration selector with pricing
- **Interactive Calendar** — pick dates, unavailable dates marked red
- Auto-calculated total price based on selected dates

### 💳 Payment Page
- Booking summary with car image, dates, duration, and total price
- Customer form (Name, Phone, Email, Driving License)
- Payment methods: UPI, Card, Cash, GPay

### ✅ Booking Confirmation
- Success modal with unique Booking ID

### 📱 Additional
- **WhatsApp Floating Button** (bottom-right) + **Phone Floating Button** (bottom-left)
- **Fully Responsive** — desktop, tablet, and mobile
- **Single Page App** — smooth navigation without page reloads

## 🚀 Getting Started

### Option 1: Open Locally
```bash
git clone https://github.com/yaminikrishna9652/jessi-self-drive-cars.git
open index.html
```

### Option 2: GitHub Pages
1. Push to GitHub
2. Go to **Settings** → **Pages**
3. Select **Branch: main** → **/ (root)** → **Save**
4. Live at: `https://yaminikrishna9652.github.io/jessi-self-drive-cars/`
